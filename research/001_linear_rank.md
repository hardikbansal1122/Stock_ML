# Experiment 001 - Linear Rank Allocator

## Hypothesis

Giving higher weights to higher-ranked stocks will improve portfolio performance.

## Results

| Metric | Equal Weight | Linear Rank |
|--------|-------------:|------------:|
| Return | -18.9993% | -21.0986% |
| CAGR | -10.2867% | -11.4921% |
| Sharpe | -0.1858 | -0.1975 |
| Max DD | -44.1189% | -45.5336% |
| Win Rate | 48.80% | 48.80% |

## Conclusion

Rejected.

Linear weighting increased concentration but reduced performance.
